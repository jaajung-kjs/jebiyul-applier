# 적용근거 생성기 (제비율 → 공사설계서 적용근거) 설계서

작성일: 2026-06-30

## 1. 목적

공사설계서의 **`적용근거` 시트**를 자동 생성하는 독립 실행형 프로그램(.exe)을 만든다.
조달청 표준 양식인 **제비율(간접공사비 적용기준) 엑셀 파일**과 공사별 파라미터(직접공사비
금액·공사기간·공사종류·계약방법)를 입력하면, **표준화된 적용근거 시트**를 산출한다.

현재 공사설계서는 표준화되어 있지 않고 담당자별로 직접 작성한다. 이 프로그램을 만드는
김에 **적용근거 출력 양식을 표준 1종으로 고정**한다. 입력 측 제비율 파일은 조달청이
주기적으로 갱신하지만 양식 자체는 표준 고정이다.

## 2. 범위

- **대상 공사종류(범용):** 건축 / 토목 / 조경 / 산업설비 / 전기·통신·소방(전문)
- **입력 제비율 파일:** 조달청 "간접공사비 적용기준" 표준 양식 (예: `붙임1 건축`, `붙임2 토목`)
  - 제비율 파일 1개가 적용근거 전 항목의 권위 있는 출처임을 검증함(아래 4절).
  - 전기·통신·소방·전문 공사는 **일반관리비 요율만** 전문 열을 쓰고, 나머지 요율은
    토목/건축 등 관련 공사업종 요율을 그대로 적용한다(제비율 파일 명시 규칙).
- **산출물:** 표준 양식 `적용근거` 시트 1장 (xlsx). 담당자가 자기 설계서에 붙여넣는다.

### 범위 밖(Out of scope)
- 설계서 본문(산출내역·일위대가 등) 파싱 — 파라미터는 사용자가 수동 입력한다.
- 산업안전보건관리비의 **실제 계상금액 계산**(×1.2 비교 등). 적용근거는 율·기준만
  표기하고, 금액 계산은 설계서 본체에서 수행한다(아래 6절 참고).

## 3. 입력 / 출력 요약

| 구분 | 내용 |
|---|---|
| 입력 1 | 제비율 xlsx 파일 (파일 선택 버튼) |
| 입력 2 | 직접공사비 금액 (숫자) → 공사규모 구간 자동 판정 |
| 입력 3 | 공사기간 (일수 입력 → 기간 구간 자동 판정) |
| 입력 4 | 공사종류 (건축/토목/조경/산업설비/전기·통신·소방전문 중 선택) |
| 입력 5 | 계약방법 (경쟁 / 수의) |
| 입력 6 | 산재율 기준 (기본값 **한전 3.656%**, 조달청 3.626% 선택 가능) |
| 출력 | 표준 적용근거 xlsx (1 시트) |

## 4. 표준 적용근거 항목셋 (출력 구조 — 확정)

제비율 파일이 아래 전 항목을 포함함을 데이터로 검증함(토목 파일 라벨: `[간접노무비]`,
`[기타경비]`, `[일반관리비]`, `[이윤]`, `[산재보험료]`, `[고용보험료]`, `[건강보험료]`,
`[연금보험료]`, `[노인장기요양보험료]`, `[퇴직공제부금비]`, `[산업안전보건관리비]`).

| # | 대분류 | 세부항목 | 적용율 산출기준 | 키 의존성 |
|---|---|---|---|---|
| 1 | 간접노무비 | — | 직접노무비 × 율 | 규모·기간·종류 |
| 2 | 경비 | 가. 공구손료 | 직접노무비 × 3% | 고정(3%) |
| | | 나. 산업재해보상보험료 | 노무비 × 율 | 한전/조달청 분기 |
| | | 다. 고용보험료 | 노무비 × 율 | 고정요율 |
| | | 라. 국민건강보험료 | 직접노무비 × 율 | 고정요율 |
| | | 마. 국민연금보험료 | 직접노무비 × 율 | 고정요율 |
| | | 바. 퇴직공제부금비 | 직접노무비 × 율 | 고정요율 |
| | | 사. 노인장기요양보험료 | 건강보험료 × 율 | 고정요율 |
| | | 아. 산업안전보건관리비 | 대상액 구간별 율(+기초액) | 규모(대상액 구간) |
| | | 자. 기타경비 | (재+노) × 율 | 규모·기간·종류 |
| 3 | 일반관리비 | — | (재+노+경) × 율 | 규모·종류(전문 별도 열) |
| 4 | 이윤 | — | (노+경+일반관리비) × 율 | 규모·계약방법 |

- 설명문·고시번호·대상공사 텍스트는 **상수**로 템플릿에 미리 박는다.
- 프로그램이 채우는 것은 적용율 값과 구간표(산안비·기타경비 등) 행값뿐이다.

### 구간 정의 (제비율 파일 기준)
- **공사규모(직접공사비):** 10억 미만 / 10–50억 / 50–300억 / 300–1000억 / 1000억 이상
- **공사기간:** 6개월 이하(183일) / 7–12개월(365일) / 13–36개월(1095일) / 36개월 초과(1096일↑)
- **산안비 대상액:** 2천만원 미만 / 5억원 미만 / 5–50억원 미만 / 50억원 이상 (구간별 율+기초액)
- 50억 이상 구간도 **제비율 실제값으로 채운다**(정책 확정). 예시 설계서의 "조달청 발표자료
  참조" 공란 처리는 따르지 않는다.

## 5. 아키텍처

```
[입력 GUI (tkinter)]
   ├─ 제비율 파일 선택
   ├─ 직접공사비 금액 / 공사기간(일) / 공사종류 / 계약방법 / 산재기준
   └─ [생성] 버튼
        │
        ▼
[룩업 엔진 (lookup.py)]
   ├─ 제비율 xlsx 로드 (openpyxl, data_only=True)
   ├─ 앵커 기반 위치 탐색: 헤더 라벨로 행/열 찾고 상대 오프셋으로 값 읽기
   ├─ (규모구간, 기간구간, 종류) → 각 항목 적용율 산출
   └─ 산재율은 사용자 선택 기준값으로 override
        │
        ▼
[출력 빌더 (builder.py)]
   ├─ 번들된 표준 적용근거 템플릿 xlsx 복사
   ├─ 지정된 셀에 적용율·구간표 값 기입
   └─ 결과 xlsx 저장 (저장 위치 선택)
```

### 모듈 구성 (단일 책임)
- `gui.py` — 입력창. 검증(필수값·숫자·구간) 후 파라미터 dict 전달. 표시만 담당.
- `params.py` — 금액→규모구간, 일수→기간구간 변환. 순수 함수, 단위테스트 대상.
- `lookup.py` — 제비율 파일에서 율 추출. 입력=파일경로+키, 출력=항목별 율 dict.
- `mapping.py` — 공사종류별 앵커 라벨·오프셋·열 규칙을 담은 설정(상수/표). 제비율
  양식이 바뀌어도 여기만 손보면 됨.
- `builder.py` — 템플릿에 값 기입 후 저장. 입력=율 dict+템플릿경로, 출력=결과 파일.
- 번들 자산: `template_적용근거.xlsx` (표준 양식, 서식 포함).

### 룩업 전략 (핵심 설계 결정)
제비율 양식은 병합 셀이 많은 복잡한 행렬표다. **앵커 기반 탐색**을 1차 전략으로 한다:
- 고정 라벨(`[간접노무비]`, `공사규모`, `(직노) x 율`, 기간 텍스트 등)을 검색해 기준
  좌표를 찾고, 상대 오프셋으로 값 셀에 접근한다. → 주기 갱신(날짜만 바뀜)에 견고.
- `mapping.py`에 종류별 앵커·오프셋을 표로 둔다. 라벨이 안 잡히면(양식 변경) **중단하고
  명확한 오류 메시지** 표시(조용히 틀린 값 내지 않음).

## 6. 산업안전보건관리비 처리 방침

산안비는 대상액 구간별 율 + 기초액 + (재+직노)×율 vs (사급재+지입재+직노)×율×1.2 중
작은 금액 비교 등 가장 복잡한 항목이다. **적용근거 시트는 율·구간표·적용기준 텍스트만
표기**하고, 실제 계상금액(×1.2 비교)은 설계서 본체에서 계산한다. 프로그램은 대상액 구간에
해당하는 율·기초액을 채우고, 적용기준 설명을 표준 텍스트로 출력한다.

## 7. 오류 처리 / 검증

- 필수 입력 누락·비숫자·구간 밖 금액 → 생성 전 경고, 진행 차단.
- 제비율 파일 앵커 라벨 미발견(시트명/헤더 불일치) → 중단 + 어떤 라벨을 못 찾았는지 표시.
- (옵션) 채운 율 옆에 출처 셀주소를 주석으로 남겨 사람이 검증 가능.
- 결과 저장 시 동일 파일명 존재하면 덮어쓰기 확인.

## 8. 배포

- PyInstaller `--onefile`로 Windows .exe 패키징. 템플릿 xlsx는 번들 자산으로 포함.
- 사용자 PC에 Python 설치 불필요.

## 9. 테스트 전략

- `params.py`: 금액·일수 → 구간 매핑 단위테스트(경계값 포함: 정확히 50억, 365일 등).
- `lookup.py`: 제공된 붙임1(건축)·붙임2(토목) 실파일로 골든 테스트 — 알려진 셀 값과 대조.
- 전기·통신 종류: 일반관리비만 전문 열, 나머지 토목 열에서 오는지 검증.
- 산재율 한전/조달청 override 검증.
- end-to-end: 샘플 파라미터 → 출력 xlsx의 핵심 율 셀 값 검증.

## 10. 미해결/추후 결정

- 출력 적용근거 **표준 템플릿 양식의 최종 레이아웃**(셀 위치·병합·서식)은 구현 단계에서
  예시 설계서를 참고해 확정한다. 항목셋(4절)은 확정.
- 제비율 파일에 전기·통신·소방 전용 일반관리비 열의 정확한 위치 — 구현 시 붙임 파일에서
  앵커 좌표 확정.
