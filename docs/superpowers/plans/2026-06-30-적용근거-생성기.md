# 적용근거 생성기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 조달청 제비율 엑셀과 수동 파라미터를 입력하면 표준 적용근거 시트(xlsx)를 생성하는 Windows .exe를 만든다.

**Architecture:** Python 모듈을 책임별로 분리한다 — 구간판정(params) / 제비율 앵커 탐색(lookup·mapping) / 템플릿 채우기(builder) / 입력창(gui) / 배선(main). 제비율 파일은 라벨 앵커로 위치를 찾아 갱신에 견고하게 읽고, 표준 적용근거는 번들 템플릿 xlsx를 복사해 율 셀만 채운다. PyInstaller로 단일 exe 패키징.

**Tech Stack:** Python 3.11, openpyxl, tkinter(표준 라이브러리), pytest, PyInstaller.

## Global Constraints

- Python 3.11 이상. 외부 의존성은 `openpyxl`, `pytest`, `pyinstaller`만 사용(GUI는 표준 tkinter).
- 제비율 파일은 `openpyxl.load_workbook(path, data_only=True)`로 읽는다(수식 아닌 계산값 필요).
- 제비율 양식이 예상과 다르면(앵커 라벨 미발견) **조용히 틀린 값을 내지 말고** 예외를 던져 중단한다.
- 모든 율 값은 제비율 시트에 % 정수/소수(예: `19.1`)로 저장되어 있으므로, 적용율로 쓸 때 `/100` 변환한다.
- 대상 공사종류(범용): 건축 / 토목 / 조경 / 산업설비 / 전기통신소방전문.
- 정책: 50억 이상 구간도 실제값으로 채운다. 산재율 기본값 = 한전 3.656%(조달청 3.626% 선택 가능).
- 테스트 픽스처는 리포지토리 루트의 실제 붙임 파일을 사용한다:
  - `붙임1. 건축공사 간접공사비 적용기준_조달청(260430 적용).xlsx` (시트 `건축제비율(4.13.)`)
  - `붙임2. 토목공사 간접공사비 적용기준_조달청(260430 적용).xlsx` (시트 `26. 4. 13.`)

## File Structure

- `src/params.py` — 금액→공사규모 구간, 일수→공사기간 구간 분류(순수 함수).
- `src/mapping.py` — 공사종류별 제비율 앵커/열/밴드 스킴 정의(상수 표).

- `src/gui.py` — tkinter 입력창(검증 후 파라미터 dict 산출).
- `src/main.py` — GUI→lookup→builder 배선, 엔트리포인트.
- `assets/template_적용근거.xlsx` — 표준 적용근거 양식(서식 포함).
- `tests/` — pytest.
- `app.spec` — PyInstaller 빌드 스펙.
- `requirements.txt`, `README.md`.

### Task 3: 제비율 앵커 매핑 정의 (mapping.py)

검증된다.

**Files:**
- Create: `src/mapping.py`
- Test: `tests/test_mapping.py`

**Interfaces:**
- Produces:
  - 상수 `SHEET_BY_KIND: dict[str, str]` — 공사종류→시트명. 단, 시트명은 갱신마다 바뀌므로
    `lookup`은 "두 번째 시트가 아닌, 데이터 시트를 라벨로 식별"한다(Task 4). 여기서는 참고용.
  - `SIZE_BASE_ROW: dict[str, int]` — 공사규모 밴드 → 데이터 블록 첫 행. 값:

  - `DATA_COL: dict[(str,str), int]` — (item, 공사종류)→데이터 열 인덱스(1-base). item ∈
    {`"간접노무비"`,`"기타경비"`,`"일반관리비"`,`"이윤"`}. 초기값은 토목 파일 기준(아래),
    Task 4에서 골든 테스트로 검증/보정한다.
  - `ANCHOR_LABEL: dict[str, str]` — item→앵커 라벨 텍스트.

```python
# src/lookup.py
"""제비율 xlsx에서 적용율을 앵커 기반으로 읽는다."""
import openpyxl
from src import mapping

def cell_text_search(ws, label):
    for row in ws.iter_rows():
        for cell in row:
            v = cell.value
            if isinstance(v, str) and v.strip().replace("\n", " ").startswith(label):
                return cell.row, cell.column
    raise LookupError(f"앵커 라벨을 찾지 못함: {label!r} (시트 {ws.title!r})")

def find_data_sheet(wb):
    for ws in wb.worksheets:
        try:
            cell_text_search(ws, "[간접노무비]")
            return ws
        except LookupError:
            continue
    raise LookupError("'[간접노무비]' 앵커가 있는 데이터 시트를 찾지 못함 — 제비율 양식 불일치")

def table_rate(path, item, kind, size, duration):
    src_kind = mapping.rate_source_kind(item, kind)
    # 건축 파일은 종류 열 분기가 없으므로 '건축' 키를 '토목' 열 인덱스로 취급(동일 레이아웃).
    col_kind = "토목" if src_kind in ("건축",) else src_kind
    col = mapping.DATA_COL[(item, col_kind)]
    row = mapping.SIZE_BASE_ROW[size] + mapping.DURATION_OFFSET[duration]
    wb = openpyxl.load_workbook(path, data_only=True)
    ws = find_data_sheet(wb)
```

```python
_FIXED_LABEL = {
    "고용보험료": "[고용보험료]", "건강보험료": "[건강보험료]",
    "연금보험료": "[연금보험료]", "퇴직공제부금비": "[퇴직공제부금비]",
    "노인장기요양보험료": "[노인장기요양보험료]",
}

def _first_number_near(ws, anchor_row, anchor_col, span=8):
    for r in range(anchor_row, anchor_row + span):
        for c in range(anchor_col, anchor_col + span):
            v = ws.cell(r, c).value
            if isinstance(v, (int, float)):
                return float(v)
    raise LookupError(f"앵커 인접({anchor_row},{anchor_col})에서 숫자 요율을 찾지 못함")

def fixed_rate(path, item):
    label = _FIXED_LABEL[item]
    wb = openpyxl.load_workbook(path, data_only=True)
    ws = find_data_sheet(wb)
    r, c = cell_text_search(ws, label)
    raw = _first_number_near(ws, r, c)
    # 시트에 %(예: 3.545) 또는 소수(0.03545)로 저장될 수 있어 정규화
    return raw / 100.0 if raw > 1 else raw

def sanan_rate(path, target_band):
    wb = openpyxl.load_workbook(path, data_only=True)
    ws = find_data_sheet(wb)
    r, c = cell_text_search(ws, "[산업안전보건관리비]")
    rate = _first_number_near(ws, r, c, span=20)
    rate = rate / 100.0 if rate > 1 else rate
    return {"rate": rate, "기초액": None}
```

```python
ITEMS = ["간접노무비","공구손료","산재보험료","고용보험료","건강보험료","연금보험료",
```

```python
"""표준 템플릿에 율을 기입해 결과 xlsx 저장."""
import os
import shutil
import openpyxl

_ASSET = os.path.join(os.path.dirname(os.path.dirname(__file__)), "assets", "template_적용근거.xlsx")

# 항목 → 율 기입 셀. 템플릿(Task7)의 항목 배치(행=3,5,7,...; 율=I열)와 일치.
ITEMS = ["간접노무비","공구손료","산재보험료","고용보험료","건강보험료","연금보험료",
         "퇴직공제부금비","노인장기요양보험료","산업안전보건관리비","기타경비","일반관리비","이윤"]
CELL_MAP = {item: f"I{3 + i*2}" for i, item in enumerate(ITEMS)}

def build_output(rates, out_path, template_path=_ASSET):
    shutil.copyfile(template_path, out_path)
    wb = openpyxl.load_workbook(out_path)
    ws = wb["적용근거"]
    for item, cell in CELL_MAP.items():
        if item in rates:
            ws[cell] = rates[item]
    wb.save(out_path)
    return out_path
```

```python
# src/gui.py
"""tkinter 입력창과 입력 검증."""
from src.mapping import KINDS

def validate_inputs(raw):
    def as_int(key, label):
        v = (raw.get(key) or "").replace(",", "").strip()
        if not v:
            raise ValueError(f"{label}을(를) 입력하세요.")
        try:
            return int(v)
        except ValueError:
            raise ValueError(f"{label}은(는) 숫자여야 합니다: {v!r}")
    kind = raw.get("kind")
    if kind not in KINDS:
        raise ValueError(f"공사종류를 선택하세요(허용: {KINDS}).")
    if raw.get("contract") not in ("경쟁", "수의"):
        raise ValueError("계약방법을 선택하세요(경쟁/수의).")
    if raw.get("sanjae_basis") not in ("한전", "조달청"):
        raise ValueError("산재 기준을 선택하세요(한전/조달청).")
    if not raw.get("jebiyul_path"):
        raise ValueError("제비율 파일을 선택하세요.")
    return {
        "jikjeop_cost": as_int("jikjeop_cost", "직접공사비"),
        "days": as_int("days", "공사기간(일)"),
        "kind": kind,
        "contract": raw["contract"],
        "sanjae_basis": raw["sanjae_basis"],
        "sanan_target": as_int("sanan_target", "산안비 대상액"),
        "jebiyul_path": raw["jebiyul_path"],
    }
```

```python
    ttk.Combobox(root,textvariable=sanjae,values=["한전","조달청"],state="readonly").grid(row=5,column=1)

        p = filedialog.askopenfilename(filetypes=[("Excel","*.xlsx")])
        if p: vars_["jebiyul_path"].set(p)
    ttk.Button(root,text="제비율 파일 선택",command=pick).grid(row=6,column=0,columnspan=2)
    ttk.Label(root,textvariable=vars_["jebiyul_path"]).grid(row=7,column=0,columnspan=2)
    def submit():
        raw = {k:v.get() for k,v in vars_.items()}
        raw.update(kind=kind.get(), contract=contract.get(), sanjae_basis=sanjae.get())
        try:
            params = validate_inputs(raw)
        except ValueError as e:
            messagebox.showerror("입력 오류", str(e)); return
        try:
            out = on_submit(params)
            messagebox.showinfo("완료", f"생성 완료:\n{out}")

    root.mainloop()
```
